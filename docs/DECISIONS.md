# Decisions

Short records. Newest last.

| ID   | Decision                                                                                                | Why                                                                                                                                                                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-1  | No database, no auth, in-memory processing                                                              | MVP for one owner on one computer; history comes later (PostgreSQL + Prisma)                                                                                                                                                        |
| D-2  | pnpm monorepo: `apps/api`, `apps/web`, `packages/shared`                                                | One repo, shared zod contract, one install                                                                                                                                                                                          |
| D-3  | One process in prod; Vite proxy in dev; no CORS                                                         | Same origin everywhere; simplest offline setup                                                                                                                                                                                      |
| D-4  | Bind `127.0.0.1` by default (`HOST`)                                                                    | Not reachable from other machines                                                                                                                                                                                                   |
| D-5  | Error envelope `{ error: { code, message, details? } }`; 500 is generic                                 | Stable client branching; no leaked internals                                                                                                                                                                                        |
| D-6  | Production mode = `apps/web/dist/index.html` exists (override `WEB_DIST_DIR`)                           | `pnpm start` always builds first; avoids `NODE_ENV=…` in scripts, which breaks on Windows. Side effect: `pnpm dev` also serves a stale build on :3001 if one exists; use :5173 in dev                                               |
| D-7  | UI copy in neutral professional Spanish; code, comments, docs in English                                | End user is a Spanish-speaking (Argentina) non-technical owner                                                                                                                                                                      |
| D-8  | exceljs, not `xlsx` (SheetJS) from npm                                                                  | The npm `xlsx` package is outdated with known vulnerabilities                                                                                                                                                                       |
| D-9  | pdfmake for PDF                                                                                         | Works offline; no headless browser (Puppeteer)                                                                                                                                                                                      |
| D-10 | multer memoryStorage, 5 MB, `.xlsx` only (Sprint 2)                                                     | Nothing touches disk; bounded memory                                                                                                                                                                                                |
| D-11 | Exports re-send the file                                                                                | Backend is the single source of truth; no server state                                                                                                                                                                              |
| D-12 | Local fonts via `@fontsource-variable/inter`                                                            | No Google Fonts/CDN at runtime                                                                                                                                                                                                      |
| D-13 | shadcn/ui set up manually (`components.json`), only used components                                     | Deterministic offline setup; no unused code                                                                                                                                                                                         |
| D-14 | No React Router, no React Hook Form                                                                     | Single screen and one file input do not need them                                                                                                                                                                                   |
| D-15 | TypeScript `~6.0.3`, not 7.x                                                                            | `typescript-eslint` 8.72 supports `<6.1`                                                                                                                                                                                            |
| D-16 | Anonymized test fixtures; `*.xlsx` gitignored outside `fixtures/`                                       | Real files contain employee names                                                                                                                                                                                                   |
| D-17 | Business logic only in `apps/api/src/import` and `apps/api/src/analysis`, pure functions                | Testable without Express; web stays presentation-only                                                                                                                                                                               |
| D-18 | Date-times are wall-clock strings `YYYY-MM-DDTHH:mm:ss`, no timezone, rounded to the second             | Excel stores local Argentina time without zone; exceljs returns it as a UTC `Date`, so UTC getters give the wall clock. Rounding drops float artifacts (`17:08:59.999` → `17:09:00`). The web slices the string, never `new Date()` |
| D-19 | More than one `desde`/`hasta` period rejects the file                                                   | User-approved 2026-11-02: one upload = one week; mixing weeks would distort the ranking                                                                                                                                             |
| D-20 | Ticket invariant mismatch excludes the row                                                              | User-approved 2026-11-02: counts that do not add up cannot be trusted                                                                                                                                                               |
| D-21 | `POST /api/analysis` returns `{ import }`; Sprint 3 adds `views`                                        | Additive change: the Sprint 2 web keeps working when views arrive                                                                                                                                                                   |
| D-22 | ZIP central-directory guard (≤ 64 MB declared), ≤ 10 000 rows, first worksheet only                     | exceljs inflates every entry in memory; this bounds memory before inflating. Declared sizes can lie, but the app binds to 127.0.0.1 and serves one owner                                                                            |
| D-23 | Accept `.xlsx` with the xlsx, octet-stream, zip or empty MIME type, plus ZIP signature check            | curl and some browsers send `application/octet-stream`; the signature catches renamed files                                                                                                                                         |
| D-24 | A branch code keeps the first `succodigo` it appears with; later mismatches are excluded with a warning | Views are keyed by branch code; a conflicting name means the row cannot be attributed safely                                                                                                                                        |
| D-25 | Rows with no content are skipped without a warning                                                      | They are not data (spacing rows); every row with content is either imported or warned                                                                                                                                               |
| D-26 | Import errors and warnings carry Spanish messages; the web shows them as-is                             | Single source for user copy on validation; the web only maps network and generic errors                                                                                                                                             |
